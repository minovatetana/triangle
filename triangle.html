📚 Корисні матеріали та формули
1. Теорема косинусів (для пошуку сторони)
a² = b² + c² − 2bc · cos α
Квадрат сторони трикутника дорівнює сумі квадратів двох інших сторін мінус подвоєний добуток цих сторін на косинус кута між ними.
2. Наслідок з теореми косинусів (для пошуку кута)
cos A = (b² + c² − a²) / (2bc)
Використовується, коли відомі всі три сторони трикутника (де a = BC — сторона навпроти кута A).
3. Теорема синусів
a / sin A = b / sin B = c / sin C = 2R
Сторони трикутника пропорційні синусам протилежних кутів (R — радіус описаного кола).
4. Визначення виду трикутника за кутом A
• Якщо cos A > 0 (a² < b² + c²) — кут A гострий.
• Якщо cos A = 0 (a² = b² + c²) — кут A прямий (90°).
• Якщо cos A < 0 (a² > b² + c²) — кут A тупий.
